# BOTPFILV3 — Asistente de análisis discursivo visual

Kit inicial del proyecto. Todavía no contiene la aplicación: Claude Code la construye a partir de `PROMPT_MAESTRO.md`.

## Contenido

| Ruta | Qué es |
|---|---|
| `PROMPT_MAESTRO.md` | Instrucciones completas para Claude Code, por etapas. |
| `docs/consigna-TFI-LV3-2025.md` | Consigna de la cátedra, referencia disciplinar del tutor. |
| `referencia-nodos/` | Piezas copiadas del repo TPIA (Nódos) para trasplantar. Se elimina al final de la Etapa 6. |
| `.gitignore` | Adaptado de Nódos (carpetas en minúscula). |

## Cómo empezar

1. Crear un repositorio vacío en GitHub (`BOTPFILV3`) y clonarlo.
2. Copiar el contenido de este kit en la raíz del repo y hacer el primer commit.
3. Crear una clave nueva en Google AI Studio para este proyecto (no reutilizar la de Nódos).
4. Abrir la carpeta en VS Code, iniciar Claude Code y escribir:
   > Leé PROMPT_MAESTRO.md y empezá por la Etapa 0. Al terminar cada etapa, detenete y mostrame el resultado.

El README definitivo lo reescribe Claude Code en la Etapa 6.
